# Agenda & Recordatorios Pro

Aplicación de escritorio de productividad y organización personal construida con Electron, React, Vite, TypeScript, Tailwind CSS y SQLite local.

## Código fuente

El archivo `agenda-recordatorios-pro.zip` contiene el proyecto completo. Descárgalo y descomprímelo para trabajar localmente.

## Tecnologías
- Electron + React + Vite + TypeScript
- Tailwind CSS
- SQLite local con better-sqlite3
- date-fns y lucide-react

## Inicio en macOS
Consulta las instrucciones del proyecto después de descomprimir el ZIP. Requiere Node.js.

## Estado
Base inicial del proyecto. Las funciones y la configuración deben probarse en el equipo destino antes de distribuir una versión de producción.
